# Contributing to OpenSensor FoA

OpenSensor Engineering maintains this fork independently. Open issues and pull
requests at [opensensor/FoA](https://github.com/opensensor/FoA), targeting `main`.
This policy governs contributions to the OpenSensor fork.

## AI-assisted contributions

**AI-assisted and AI-generated contributions are welcome.** AI use alone is not
grounds for rejection. All contributions are reviewed for correctness, clarity,
reproducible evidence and compatibility with this repository's existing licenses.

The submitting contributor owns the change: review the output, explain its
behavior and limitations, and help address review feedback. When AI materially
assists code or reverse-engineering conclusions, briefly name the tool/model and
describe the human review and validation performed. Private prompts and tooling
are not required.

Describe the problem, resulting behavior, test commands and results. For hardware
claims, record the source revision, chip/board and toolchain. State failures and
untested paths; contributions without a test board are also welcome. A successful
compile or model assertion is not a device test.

Preserve attribution and existing license notices, and only submit material you
have the right to contribute. Remove credentials, signing keys and private logs.
Keep review feedback specific and respectful. All pull requests receive human
review; AI use neither guarantees acceptance nor exempts a change from review.

See the [OpenSensor ESP repository index](https://github.com/opensensor/esp-wifi-hal/blob/main/FORKS.md)
for related work, integration status and S3 validation. Use this project's
existing build instructions for technical setup. Upstream submission policies
and destinations do not replace this fork's contribution policy.
